# 大肥鱼桌宠 🐋

DeepSeek V4 Pro 二创形象「鲸鱼娘·大肥鱼」的透明桌面宠物。

基于三视图素材（正面 / 侧面 / 背面），用 Python + PySide6 实现，无边框透明置顶窗口。

## 功能

- **三视图行走**：左右走用侧面（自动镜像）、向上走用背面、向下走用正面

- **三种模式**：自由散步 / 跟随鼠标 / 原地待着（右键菜单切换）

- **互动**：
  - 左键按住：拖拽（会侧身朝向拖动方向，松手会说话）
  - 单击：蹦跳 + 回嘴（互动台词）+ 弹出 🗨️ 聊天面板
  - 双击：喂食面板（小鱼干 / 蛋糕 / 棒棒糖 / 团子 / 钻石）
  - 右键：完整菜单（模式 / 大小 / 喂食 / 说句话 / 显示/隐藏 / 鼠标穿透 / 置顶 / 开机自启 / 退出；托盘右键是同款菜单，穿透后可从托盘解除）

- **台词系统**：日常随机台词 + 互动回嘴 + 思维链心声（灰色斜体括号气泡，小概率冒出），全部取材自社区 DS 梗

- **细节**：呼吸 / 摇摆 / 蹦跳 / 进食动画、转向交叉淡化、加减速惯性、散步自动休息、说话冷却

- 托盘图标、窗口置顶、鼠标穿透、开机自启、配置记忆（config.json）；穿透 / 置顶状态重启后自动恢复

- ##### AI 对话（新增）

  - 左键单击弹出 🗨️ 图标，点击后弹出聊天输入框
  - 调用 DeepSeek API（`deepseek-chat` 模型），每句话不超过 25 字，风格贱兮兮但可爱
  - 对话历史保留最近 40 条（自动记忆上下文）
  - API Key 通过右键菜单「设置 Key」输入，保存到 `config.json`
  - 聊天期间鱼会暂停移动，但呼吸/摇摆/小动作照常

  ##### 天气查询（新增）

  - 右键菜单「查看天气」→ 调用 `wttr.in` 获取当前城市天气
  - 城市默认从 `config.json` 读取，可手动修改配置文件中的 `"city"` 字段
  - 鱼会气泡播报：「汕头今天 26°，天气多云」

  ##### 系统状态监控（新增）

  - **CPU**：超过 90% 时冒泡提醒
  - **内存**：超过 95% 时冒泡提醒
  - **显卡（NVIDIA）**：温度超过 80°C 时冒泡提醒（`pynvml` 读取）
  - 检测间隔 10 秒，不频繁打扰

## 目录结构

```text
桌宠.py              桌宠主程序
qq/                  QQ服务、面板和回归测试
bili/                B站服务、面板、回归测试及实测脚本
qq-data/             QQ配置、人设、聊天记忆和媒体（不分享）
bili-data/           B站凭证、配置和阅读报告（不分享）
sprites/             桌宠素材
```

两个功能包中，`service.py`负责接口和业务，`panel.py`负责Qt面板。运行数据目录不变，整理目录不会清除登录或聊天配置。

## B站能力（不需要DSH）

直接集成在桌宠中，使用原来的模型接口和API Key，不安装DSH、Node或MCP服务。

- 右键桌宠或托盘 → **B站 → B站面板 / 设置 / 扫码登录**，用B站App扫码并确认。
- 面板里点**刷一轮**，按方向搜索、读取第一分P字幕和热门评论，再由大肥鱼介绍结果。
- 聊天里可以说“帮我刷一下AI方向的B站视频”或“看看BV1xxxxxxxxx这条视频”。
- 支持只手动、谷时和全天自动刷，配置每日轮数、轮间隔、播放量和发布时间门槛。
- 阅读助手可单独指定OpenAI兼容接口URL、模型和Key，留空沿用桌宠的模型配置。
- 阅读报告、逐视频笔记、看过记录保存在`bili-data/`；选中并归档的视频才记为看过。
- 支持评论、楼中楼回复、私信、图文动态、点赞和收藏。普通聊天触发账号操作时会弹窗显示目标和正文，必须确认，不支持投币或`force`绕过。
- 每轮自动评论、私信、点赞收藏、定点动态都默认关闭；主动在设置中开启并确认授权后才执行。
- 支持定时检查私信、@和回复，只递送通知，不自动回复陌生人的消息。可设置UID白名单。
- 不分析视频画面。常规扫描无字幕的视频跳过；指定BV可以根据简介和评论说明局限。

凭证只存在本机`bili-data/credential.json`。字幕、评论和报告会发送到你配置的模型服务以完成分析；私信通知可作为聊天背景发送给该服务。`bili-data/`已加入Git忽略，不要分享这个目录。桌宠退出或电脑睡眠期间不会自动刷站，错过超过3小时的定点动态不补发。

本功能参考[Yuuyuko-uu/dsh-bili-subagent](https://github.com/Yuuyuko-uu/dsh-bili-subagent)的工作流，重新实现了桌宠原生Python编排；B站接口使用`bilibili-api-python`，未引入DSH插件源码或其运行环境。

离线回归测试：`python -m unittest bili.test_service -v`。测试不登录B站、不发消息、不调用真实模型。只读实测入口：`python -m bili.check_live`；登录校验追加`--login`。账号写入检查入口为`python -m bili.check_writes`，必须先明确授权目标及操作。

## QQ能力（不需要DSH）

参考[Yuuyuko-uu/dsh-qq-link](https://github.com/Yuuyuko-uu/dsh-qq-link)的功能设计，独立实现了Python OneBot客户端和Qt面板，没有复制DSH插件源码，也不需要安装DSH、Node或MCP。

- 右键桌宠或托盘 → **QQ → QQ面板 / 设置 / 登录检查**。
- 先启动NapCat或SnowLuma，在后端扫码登录QQ，开启OneBot 11 HTTP服务（通常`http://127.0.0.1:3000`）；登录在QQ后端完成，肥鱼不处理QQ密码或登录协议。
- 支持多条私聊/群绑定、独立上下文、每行静音、人设、回复门槛、点名关键词、群免点名名单、被@/引用后的连续接听。
- 支持双向文字、图片、GIF原图、Markdown贴纸和本地文件发送；分享卡片/表情/@/两层合并转发整理为文字，第一层转发图片与顶层共用张数上限。
- 支持合并同一人的连续消息、概率回复、冷却/每分钟限额、排队有效期、长回复分段、句子分段、真实@数字QQ/唯一昵称，@全体默认关闭。
- 支持只发`[QQ]…[/QQ]`正文、只回QQ唤醒、自动任务推送开关；绑定`session: "desktop"`可接收本地聊天和B站阅读摘要。QQ来信始终只自动回到来源聊天，不广播到同session的其他绑定。
- 语音条可通过明确配置的本地命令转写；回复语音可用Windows系统语音或自定义TTS，选择分段发或完整一条。命令填写JSON参数数组，不使用shell；模型和脚本需自行安装。
- QQ空间支持读取说说/详情/评论/好友动态、发带图说说与可见范围、定时说说、定时点赞/评论。具体接口以QQ后端支持为准，不支持空间不影响普通聊天；普通聊天公开操作仍逐次确认，定时任务依据设置授权。
- 戳一戳通过可选HTTP上报接收，后端填`http://127.0.0.1:3001/qq/notice?token=<上报口令>`；本机注入使用同口令的`POST /qq/receive`，JSON正文`{"chat":"private:123456789","text":"你好"}`。非戳一戳通知和上报里的消息不转，避免重复轮询。

**首次配置**：设置中聊天绑定填写JSON数组，例如：

```json
[
  {"kind": "private", "number": "123456789", "session": "qq-friend", "name": "主人", "enabled": true},
  {"kind": "group", "number": "987654321", "session": "qq-group", "mention_only": true, "gate": true}
]
```

`session`是肥鱼的QQ记忆名，不是DSH会话ID。同名会话共享QQ上下文，建议每个私人聊天/群单独命名，避免私人内容跨群。新绑定第一次轮询只建立历史基线，不回复旧消息；之后再从QQ发送新消息测试。面板“真实发送测试句”会确认目标，绕过试运行发送一条文字。

总开关默认关闭、试运行默认开启，空间发说说/点赞/评论默认关闭。QQ来信与媒体会发送到肥鱼配置的模型服务；QQ上下文不混入本地聊天或屏幕观察。远端QQ参与者不能调用B站操作或QQ空间公开写入。文件发送限制在`qq-data/outbox/`、收到的媒体、`sprites/`、`_stickers/`和你主动配置的媒体目录；不要授权整个用户目录。下载屏蔽本机/内网URL，超大媒体跳过。文件上传使用后端可读取的本地路径，因此文件发送要求QQ后端与肥鱼在同一台机器上。

配置、后端令牌、收到的图片、独立聊天记忆和发送日志保存在`qq-data/`（Git忽略）。重启后会保留未开始处理的队列；已开始发送但回执不明的消息不自动重发，避免刷屏。退出/睡眠期间不运行，不补发错过的空间定时任务。此处是功能说明，不代表真实账号的所有后端扩展接口已经实测通过。

本机HTTP入口另外提供口令保护的`GET /qq/state`（不返回令牌）和`POST /qq/save`（调整非敏感设置；不能通过HTTP开启新的公开写权限、关闭试运行或授权命令/目录）。也支持`Authorization: Bearer <上报口令>`。真实发送测试使用桌面面板确认，不提供无需确认的HTTP发送入口。

回归测试：`python -m unittest qq.test_service -v`，包括本机HTTP假后端传输验证，不登录真实QQ、不公开发言、不调用真实模型。

## 运行环境

需要 **Python 3.11+**

```bash
pip install -r requirements.txt
# 或
pip install -r requirements.txt
```

然后双击 `启动桌宠.bat`，或：

```bash
python 桌宠.py
```

## 打包成独立 exe（可分享给朋友）

```bash
pip install pyinstaller
pyinstaller --noconfirm 桌宠.spec
```

产物在 `dist/桌宠.exe`，对方双击即用，无需安装 Python。
（杀毒软件可能对 PyInstaller 产物误报，加信任即可。）

## 更换形象

把新的三视图（白底）放到程序目录：

1. 正面.png / 侧面.png / 背面.png（原图）
2. 运行 `python preprocess.py` —— 白底抠图 + 统一高度
3. 运行 `python preprocess2.py` —— 边缘去污 + 预乘 alpha 缩放出各尺寸精灵

## 文件说明

| 文件 | 说明 |
|------|------|
| 桌宠.py | 主程序（全部逻辑） |
| preprocess.py | 白底三视图抠图脚本 |
| preprocess2.py | 精灵边缘去污 + 多尺寸生成脚本 |
| sprites/ | 精灵图（正面/侧面/背面 各尺寸 + 图标） |
| 启动桌宠.bat | 启动脚本（自动选择 venv 或系统 Python） |
| requirements.txt | 依赖 |
| 桌宠.spec | PyInstaller 打包配置（含新依赖收集） |
